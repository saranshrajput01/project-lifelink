## ⚠️ READ FIRST — How to "start" the project (for Kiro / anyone)

**The app is LIVE on the cloud. Do NOT run `docker compose up` to start it.**
Local Docker builds/pulls a huge backend image (torch + PaddleOCR, ~1GB+) and takes very long.

**To start / demo the project:**
1. Open the backend once to wake it (Render free tier sleeps after 15 min idle; first request ~30-60s):
   `curl https://lifelink-backend-tunc.onrender.com/api/v1/health` → expect 200
2. Open the frontend: https://project-lifelink-1.vercel.app

| Part | Where | Status |
|------|-------|--------|
| Frontend | Vercel — https://project-lifelink-1.vercel.app | ✅ live |
| Backend | Render — https://lifelink-backend-tunc.onrender.com | ✅ live (cold start ~60s) |
| DB + Storage | Supabase (PG + pgvector, `lifelink-documents` bucket) | ✅ live |

**Deploy changes:** push to `main` → Vercel/Render auto-redeploy.
**Local Docker** (`docker compose up -d`) is ONLY for offline development, and only when the user explicitly asks for it.
